# SpaceSharp Scoop bucket

The [Scoop](https://scoop.sh) bucket for [SpaceSharp](https://spacesharp.app), a free, open-source disk space analyzer for Windows that draws a drive as a zoomable treemap.

## Install

```powershell
scoop bucket add spacesharp https://github.com/SpaceSharpApp/scoop-bucket
scoop install spacesharp/spacesharp
```

## Update

```powershell
scoop update spacesharp
```

This installs the portable build for 64-bit or 32-bit Windows. Settings are kept in your user profile, so they survive updates and uninstalling.

The app itself lives at [SpaceSharpApp/SpaceSharp](https://github.com/SpaceSharpApp/SpaceSharp). Report problems there.
